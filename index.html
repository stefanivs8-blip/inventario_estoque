Configuração Inicial

Conecte o sistema ao seu repositório GitHub para salvar os dados.

Crie um repositório público no GitHub (ex: portocel-inventario)
Acesse Settings → Developer Settings → Personal Access Tokens → Tokens (classic)
Gere um token com permissão repo (acesso total ao repositório)
Preencha os campos abaixo e clique em Conectar

O token fica salvo apenas no seu navegador, nunca é enviado a terceiros.
